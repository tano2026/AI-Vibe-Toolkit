# /ui-check

1. Xác nhận app đang chạy (lệnh dev trong `AGENTS.md`). Chưa chạy thì chạy.
2. Mở bằng browser tích hợp, chụp ở **1440px** và **390px**.
3. So với `DESIGN.md`. Lập bảng: `màn | vấn đề | token đúng phải là gì`. Kiểm: màu, font, spacing, radius, hierarchy (tối đa 3 cấp), tương phản ≥ 4.5:1, focus bàn phím, alt ảnh, chữ bị tràn ở 390px.
4. **Chưa sửa.** Trình bảng và chờ tao duyệt. Đính kèm ảnh chụp làm bằng chứng.
