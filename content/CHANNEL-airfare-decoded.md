## 3. Visual System

**Pollinations style prefix (cố định mọi video):**
```
minimalist stick figure illustration, hand-drawn black ink line art style, clean white background, single red accent color for key element, simple airport and airplane doodle elements, editorial cartoon style, no text, no words, 16:9
```

**Quy tắc:**
- Chỉ đổi phần mô tả scene SAU prefix, không đổi prefix → consistency
- Red accent = 1 element quan trọng nhất mỗi frame (giá vé, hành lý, con dấu visa...)
- ~12–18 hình/video (1 hình per 30–40s voiceover)
- Thumbnail: Canva, cùng style — stick figure + 3-4 từ lớn + red accent (học The Happy Brain / Dopamine Secrets)

**Pipeline:** Script (Claude/DeepSeek creative tier) → Pollinations images (fixed prefix) → ElevenLabs voiceover → MoneyPrinterTurbo ráp → CapCut polish → Canva thumbnail. Trùng 100% pipeline Actually Tested, chỉ khác style prefix + script bank.

## 5. Guardrails

- **Compliance YouTube:** không mass-produce; mỗi script có insider detail riêng; bật disclosure "altered/synthetic" nếu cần; KHÔNG dùng chung footage/hình giữa các video (variation guard = hard rule)
- **Accuracy:** quy định (DOT, EU261, visa) PHẢI verify bằng web search trước khi viết — luật đổi liên tục; sai quy định = mất trust ngách này ngay
- **Không legal advice:** luôn frame "check with the airline/embassy" cho visa/refund edge cases
- **Tách kênh:** không cross-post nguyên video sang Trùm Sân Bay — chỉ tái sử dụng INSIGHT, làm lại content tiếng Việt riêng
