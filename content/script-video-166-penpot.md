## Script voiceover (ElevenLabs-ready)
Penpot là design tool mã nguồn mở, làm gần như mọi thứ Figma làm được. Vẽ UI, prototype click thử, làm việc nhóm cùng lúc, xuất thẳng CSS cho dev copy.
Khác biệt lớn nhất là file design lưu dạng SVG và CSS chuẩn mở, không phải định dạng đóng của riêng ai. Muốn tự host trên server riêng để giữ toàn bộ dữ liệu khách hàng trong nhà, chỉ cần một lệnh Docker Compose.
Bản cloud miễn phí không giới hạn số project hay số file, không phải bản dùng thử. Nếu team nhỏ, làm brand cho nhiều khách, đây là cách tránh trả phí theo đầu người mà vẫn có công cụ chuyên nghiệp.
Điểm yếu là file quá nặng thì vẫn load chậm hơn Figma, và hệ plugin chưa phong phú bằng. Nhưng nếu ưu tiên tự chủ dữ liệu và tiết kiệm chi phí, Penpot đáng thử.
