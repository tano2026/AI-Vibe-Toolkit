# Script Video 311 — Ponytail

## Thông tin
- Tool/Repo/Skill liên quan: /skills/ponytail.md
- Platform: TikTok / YouTube Shorts
- Thời lượng dự kiến: ~50 giây

## Hook (3 giây đầu)
"Bốn mươi bốn nghìn sao trong chín ngày, chỉ vì một file prompt dạy AI lười đi."

## Script voiceover (ElevenLabs-ready)
[Đoạn 1 — vấn đề/pain point]
Hỏi AI code một cái chọn ngày, nó tự cài thêm thư viện, viết component riêng, thêm cả file kiểu dáng, rồi còn bàn về múi giờ. Việc đơn giản bị làm phức tạp lên gấp mười lần.

[Đoạn 2 — giới thiệu giải pháp]
Ponytail nhồi vào AI agent tính cách một ông senior lâu năm lười biếng nhất công ty, nhìn năm mươi dòng code rồi rút xuống còn một dòng. Nguyên tắc là luôn hỏi có sẵn tính năng gốc chưa, có thư viện chuẩn chưa, trước khi cho phép viết code mới.

[Đoạn 3 — demo/cách làm]
Cùng một yêu cầu chọn ngày, có ponytail thì nó nhận ra trình duyệt đã có sẵn ô chọn ngày, trả về đúng một dòng, không cài gì thêm. Cài được cho hơn mười loại agent khác nhau, chỉ cần copy đúng file luật vào đúng thư mục.

[Đoạn 4 — kết + CTA]
Có một điều cần nhớ, con số tám mươi đến chín mươi bốn phần trăm ít code hơn là mức trần cho từng việc riêng, không phải trung bình chung, đọc kỹ trước khi tin tuyệt đối. Link file gốc tao để trong kho, comment "ponytail" là gửi.

## Ghi chú quay (OBS)
- Cảnh 1: Cảnh code phình to từ 1 yêu cầu đơn giản — lúc hook/pain point
- Cảnh 2: Hình minh hoạ "ông senior tóc ngựa" (nếu có ảnh từ repo) — lúc giới thiệu
- Cảnh 3: Before/after code (50 dòng → 1 dòng, ví dụ date picker) — lúc demo
- Cảnh 4: Show GitHub star tăng vọt trong vài ngày — lúc kết
