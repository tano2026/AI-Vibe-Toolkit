## Hook (3 giây đầu)
Amazon tự làm luôn bộ kết nối để Claude điều khiển AWS bằng lời nói.

## Script voiceover (ElevenLabs-ready)
Nếu hạ tầng của mày chạy trên AWS, có một bộ MCP server chính chủ Amazon làm ra, cắm vào Claude là gõ tiếng người điều khiển được luôn.
Muốn tạo một máy chủ ảo, muốn xem chi phí S3 tháng này tốn bao nhiêu, muốn quản lý Lambda, chỉ cần gõ câu lệnh bình thường thay vì nhớ cú pháp dòng lệnh AWS.
Đây không phải một server đơn, mà là cả một bộ nhiều server con, mỗi cái phụ trách một mảng riêng, mày cắm cái nào cần dùng thôi.
Vì là hàng chính chủ AWS Labs nên bám sát API thật, cập nhật đều đặn.
Nhưng nhớ, cái này chỉ có ích nếu hạ tầng của mày thật sự đang chạy trên AWS.
