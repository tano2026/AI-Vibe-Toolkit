## Script voiceover (ElevenLabs-ready)
Mario Zechner, người viết ra thư viện game libGDX nổi tiếng, chán Claude Code giật lag terminal, chán agent khác nhồi nhét hai trăm tính năng mà chỉ dùng năm cái.
Ông làm ra Pi, một coding agent chỉ có bốn công cụ lõi, đọc file, ghi file, sửa file, và chạy lệnh, system prompt chưa tới một ngàn token.
Nghe tưởng thiếu tính năng nhưng ngược lại, Pi tự mở rộng được bằng chính extension viết bằng TypeScript, thậm chí có người đã chạy được cả game Doom bên trong nó.
Hỗ trợ mười lăm nhà cung cấp AI khác nhau, dùng được luôn tài khoản Claude Pro hoặc ChatGPT Plus có sẵn, không bắt buộc phải mua API riêng.
Cài một dòng lệnh duy nhất, npm install global tên gói pi coding agent.
