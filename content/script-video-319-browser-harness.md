[Đoạn 1 — vấn đề/pain point]

[Đoạn 2 — giới thiệu giải pháp]
Browser Harness của team Browser Use nối thẳng một LLM vào Chrome thật qua một kết nối duy nhất. Gặp bước thiếu, ví dụ tải file lên, nó tự viết ngay đoạn code còn thiếu trong lúc đang chạy, lưu lại dùng cho lần sau.

[Đoạn 3 — demo/cách làm]
Chỉ khoảng năm trăm chín mươi hai dòng Python, cực nhẹ. Không rành code cũng cài được, dán một đoạn prompt cho Claude Code hoặc Codex là nó tự cài, tự kết nối hộ.

[Đoạn 4 — kết + CTA]
Càng chạy nhiều lần càng khoẻ hơn, vì code đã viết lần trước được giữ lại dùng tiếp. Có cả bản cloud miễn phí ba trình duyệt chạy song song, không cần thẻ. Link cài đặt tao để trong kho, comment "harness" là gửi.
