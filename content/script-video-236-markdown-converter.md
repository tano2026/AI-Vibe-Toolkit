## Hook (3 giây đầu)
"Đừng bao giờ đưa PDF thẳng vào AI, làm cái này trước."

## Script voiceover (ElevenLabs-ready)
Mỗi lần tao đưa một file PDF hợp đồng dài vào AI để nghiên cứu, bảng biểu hay bị vỡ cấu trúc.

Cách tao xử lý bây giờ là convert file trước sang markdown bằng một công cụ tên MarkItDown.

Chỉ một dòng lệnh. File PDF, file Word, file Excel, biến hết thành văn bản sạch, bảng biểu giữ nguyên cấu trúc.

Công cụ này còn có khóa an toàn. Nó không nhận link web, chỉ nhận file local. Và nó không bao giờ ghi đè file gốc của mày.

Việc nhỏ nhưng tiết kiệm cực nhiều thời gian khi nghiên cứu tài liệu dài cho các dự án lớn.

## Ghi chú quay (OBS)
- Cảnh 1: File PDF hợp đồng dài mở lên
- Cảnh 2: Terminal chạy lệnh convert
- Cảnh 3: File markdown sạch hiện ra, bảng biểu rõ ràng

## Caption/Sub note (CapCut)
Highlight dòng lệnh terminal khi voiceover nói "chỉ một dòng lệnh".

## Thumbnail idea (Canva)
Chữ "PDF LOẠN → MARKDOWN SẠCH" với icon mũi tên chuyển đổi.
