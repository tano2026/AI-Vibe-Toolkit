## Script voiceover (ElevenLabs-ready)
Claude Code mặc định chỉ nói chuyện với đúng một hãng model. Mọi request, dù là việc nặng hay việc lặt vặt như đọc file, đều tính vào cùng một hoá đơn.

Claude Code Router chèn một lớp trung gian chạy ngay trên máy mày. Nó nhận request từ Claude Code rồi tự quyết định gửi đi đâu. Việc nền, việc lặt vặt, đẩy sang model rẻ như DeepSeek. Việc cần suy luận sâu, mới giữ lại cho model xịn.

Cài đúng hai dòng lệnh, tạo một file cấu hình khai provider mày muốn dùng, xong gõ ccr code thay vì claude như bình thường. Từ giờ mọi phiên làm việc tự động chia việc theo đúng độ khó, không phải tự nhớ đổi model bằng tay nữa.

## Ghi chú quay (OBS)
