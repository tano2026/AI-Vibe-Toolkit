# Script Video 274 — Prime Agent: Coding Agent Tự Học Qua Session

## Thông tin
- Tool/Repo liên quan: /repos/prime-agent.md

## Hook (3 giây đầu)
Coding agent bình thường quên hết mỗi lần đóng terminal. Con này thì không.

## Script voiceover (ElevenLabs-ready)

[Đoạn 1 — vấn đề]
Vấn đề lớn nhất của coding agent là mỗi lần mở lại, nó quên sạch cách mày code, quên luôn cả quy tắc dự án.

[Đoạn 2 — giới thiệu giải pháp]
Prime Agent giải quyết bằng thứ gọi là Continual Harness. Sau mỗi lần làm việc, gõ lệnh refine, nó tự phân tích và cập nhật lại cách nó làm việc cho khớp với mày.

[Đoạn 3 — demo/cách làm]
Đặc biệt hơn, nó chạy trên daemon nền. Ngắt SSH giữa chừng, agent vẫn tiếp tục chạy task. Kết nối lại bất cứ lúc nào là thấy nó vẫn đang làm.

[Đoạn 4 — kết + CTA]
Đây là hướng agent chạy dài hạn thực sự tự chủ. Link repo dưới bio, follow để coi thêm agent hay.
