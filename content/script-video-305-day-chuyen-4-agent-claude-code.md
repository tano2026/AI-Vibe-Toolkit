## Script voiceover (ElevenLabs-ready)
[Đoạn 1 — vấn đề/pain point]
Một con AI viết code xong tự test xong tự duyệt luôn thì nó sẽ nghiêng về hướng nào nó vá được, chứ không nói thật là thiết kế đang sai. Mày nhận về một mớ test xanh nhưng cảm giác an toàn đó là giả.

[Đoạn 2 — giới thiệu giải pháp]
Cách sửa là tách ra bốn con AI, mỗi con một vai, trong Claude Code. Một con chỉ lên kế hoạch. Một con chỉ code. Một con chỉ test. Một con chỉ duyệt và không được sửa gì hết.

[Đoạn 3 — demo/cách làm]
Bốn con này không nói chuyện trực tiếp với nhau. Chúng để lại file trong một thư mục chung, con sau đọc file con trước rồi làm tiếp. Mày chỉ cần gõ một lệnh duy nhất là ship, kèm mô tả tính năng, rồi đi ngủ. Sáng ra mở đúng một file để biết là chốt, cần sửa, hay là chặn lại.

[Đoạn 4 — kết + CTA]
Setup chỉ năm file text, cài trong năm phút. Link đầy đủ năm file copy về dùng ngay, tao để trong kho, comment "kho" là gửi.
