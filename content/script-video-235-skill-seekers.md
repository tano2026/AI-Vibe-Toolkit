# Script Video 235 — Skill Seekers

## Thông tin
- Tool/Repo/Skill liên quan: [skills/skill-seekers.md](../skills/skill-seekers.md)

- Thời lượng dự kiến: ~45 giây

## Hook (3 giây đầu)
"Skill này biến bất kỳ repo GitHub nào thành công cụ AI hiểu được."

## Script voiceover (ElevenLabs-ready)
Tao có một kho lưu trữ hàng trăm công cụ AI. Việc tốn thời gian nhất là biến một repo GitHub thành một file hướng dẫn AI đọc được.

Skill này tự động hóa việc đó. Đưa vào một link doc, một repo, hoặc một file PDF. Nó tự trích ra quy trình, lệnh, và luật quan trọng.

Phần dài dòng chi tiết được tách riêng ra. Phần script chạy được để riêng. File chính chỉ giữ lại hướng dẫn ngắn gọn.

Quan trọng nhất là nó luôn ghi rõ nguồn gốc, không bao giờ tự nhận là của mình.

Đây chính là quy trình tao đang làm tay mỗi ngày để xây kho công cụ AI cho content Việt Nam.
