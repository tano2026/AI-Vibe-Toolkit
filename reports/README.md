# /reports/ — Weekly reports từ Focus Mode

> Xem cơ chế đầy đủ: `agents/research-analytics-pro/FOCUS-MODE.md`

Mỗi pack đang bật Focus Mode có 1 subfolder riêng. File đặt tên `YYYY-Wnn.md` (ISO week),
mỗi file là 1 snapshot Ranked Opportunity List đầy đủ tại thời điểm đó — không ghi đè, giữ
lịch sử để so sánh delta tuần-qua-tuần.

Không phải file trong `/content/` (script video) hay `/repos, /mcps, /skills` (knowledge base
công cụ) — đây là **output nghiên cứu định kỳ**, đọc bởi Hermes khi chạy Focus Mode và bởi
Nobitano khi cần xem lịch sử gap thị trường.
